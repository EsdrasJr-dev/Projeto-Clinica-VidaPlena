# Sistema de Agendamento da Clínica VidaPlena

Este projeto foi desenvolvido por nosso grupo como atividade de Modelagem e Desenvolvimento Orientado a Objetos. O sistema representa os principais elementos de uma clínica e permite organizar pacientes, médicos e consultas.

## Funcionalidades

- Cadastro de médicos, convênios e pacientes particulares ou de convênio.
- Autorização de atendimento para pacientes de convênio.
- Agendamento, realização e cancelamento de consultas.
- Consulta da lista de atendimentos e seus estados.
- Registro de prescrições após a realização da consulta.
- Validação para impedir agendamentos no passado ou no mesmo horário para um médico.

## Estrutura do projeto

- `app`: contém o menu e a interação com o usuário.
- `model`: contém as classes que representam os elementos da clínica.
- `service`: contém as regras relacionadas à agenda de consultas.
